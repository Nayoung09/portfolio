문제

Spotfire 기본 기능으로 풀리지 않는 전처리가 반복됐고, 파이썬을 모르면 분석이 멈췄습니다.

한 일

컬럼명과 목적만 넣으면 실행 코드와 매뉴얼이 나오는 커스텀 봇을 만들고, 동료 테스트를 거쳐 기획 업무 3건에 적용했습니다.

결과

필요한 데이터를 확인하기까지 2~3일에서 10분 이내 (개발팀 요청 대비)

봇에 넣었던 실제 데이터. 주문번호 여러 개가 한 칸에 붙어 있어 그대로는 분석할 수 없었습니다.

배경 설명

더편한샵은 약국과 병의원이 의약품을 온라인으로 주문하는 B2B 이커머스입니다. 회원은 개인 소비자가 아니라 약국과 병의원이고, 같은 상품을 정기적으로 다시 주문하는 경우가 많습니다.

이 프로젝트에 나오는 용어 설명
Spotfire
회사에서 쓰던 데이터 분석 및 시각화 도구입니다. 기본 기능으로 안 되는 작업은 파이썬 코드가 필요했습니다.
전처리

데이터 함수
Spotfire 안에서 파이썬 코드를 실행하는 기능입니다.

한 줄 요약

퀵오더 로그를 분석하다 막힌 지점을, 파이썬을 몰라도 쓸 수 있는 도구로 만들었습니다.

01발견

퀵오더 사용 흐름을 보려는데, 로그가 한 칸에 붙어 있었습니다

퀵오더 사용 로그는 Grafana로 실시간 확인만 가능했습니다. 저장된 데이터에는 모달 열기, 리스트 담기, 주문 클릭 이력이 한 셀에 붙어 있어 사용 흐름을 해석할 수 없었습니다.

주문 데이터의 주문번호도 여러 건이 한 값으로 붙어 나오는 등, 비슷한 문제가 다른 분석에서도 반복됐습니다.

02정의

개인의 실력 문제가 아니라, 팀의 반복 비용으로 봤습니다

Spotfire 내장 기능으로 처리되지 않는 전처리마다 파이썬이 필요했습니다. 팀원 대부분이 파이썬에 익숙하지 않아 매번 개발팀에 데이터를 요청했고, 개발팀 공수에 따라 데이터를 확인하기까지 2~3일이 걸렸습니다.

개발팀 의존으로 생기는 병목을 줄이고, 팀원이 원하는 데이터를 직접 확보해 의사결정 시간을 줄이는 것을 목적으로 정했습니다.

03가설과 검증

요구사항을 넣으면 실행 코드가 나오는 봇을 만들었습니다

데이터 컬럼명과 분석 목적을 입력하면, Spotfire에 바로 적용할 수 있는 파이썬 코드와 변수별 상세 매뉴얼이 함께 나오도록 ChatGPT 커스텀 봇을 학습시켰습니다.

기획자가 입력하는 것

데이터 컬럼명
분석 목적 (예: 한 셀에 붙은 이벤트 이력을 행 단위로 나누기)

봇이 돌려주는 것

Spotfire 데이터 함수에 붙여 넣을 파이썬 코드
변수별 설명과 적용 순서 매뉴얼

오류 내용을 다시 입력하면 코드가 자동으로 수정되는 흐름까지 넣어 사용법을 4단계로 줄였습니다. 실제 주문 데이터 전처리로 사용 테스트를 진행하며 프롬프트를 다듬었습니다.

한 셀에 여러 값이 연결된 주문번호 데이터를 봇에 넣고 "값을 낱개로 분리"라고 입력하자 파이썬 코드가 생성됐고, 이 코드를 Spotfire에 붙여 넣어 개발팀 도움 없이 바로 분리했습니다.

04결정

코드만 주지 않고, 매뉴얼을 함께 주기로 했습니다

직접 내린 결정

봇이 실행 코드와 함께 변수 설명과 적용 순서 매뉴얼을 출력하도록 설계했습니다.

근거코드만 받으면 오류가 났을 때 파이썬을 모르는 사용자는 다시 막힙니다. 매뉴얼이 있어야 팀원이 혼자서도 고칠 수 있었습니다.

AI를 요구사항과 실행 코드 사이의 번역기로 두는 구조가 가장 안정적이었습니다. 코드만 받으면 오류가 났을 때 다시 막히기 때문에, 변수 설명과 적용 순서를 함께 출력하도록 했습니다.

개인이 쓰는 도구로 끝내지 않기 위해 팀원 대상 Spotfire 교육을 두 차례 진행했습니다.
